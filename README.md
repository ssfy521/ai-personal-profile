## 维护与版本回退

每次修改都执行 Git 提交并推送，提交说明写清修改原因。未提交的编辑不在 Git 历史中。

```bash
git pull --ff-only
# 编辑 README.md 后：
git add README.md
git commit -m "docs: update personal profile"
git push

# 查看历史：
git log --oneline
# 撤销指定提交并保留历史（将 COMMIT_SHA 替换为实际提交号）：
git revert COMMIT_SHA
git push
```
